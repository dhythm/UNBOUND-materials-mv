# UNBOUND — Opusへの映像制作指示

## 依頼と現在地

素材パックはこの文書の一つ上のフォルダにある。素材収集・静止画生成・SVG作成が完了している。まだRemotionプロジェクトや完成動画はない。人物動画もユーザーから受領済みで、切り抜き動画とRGBA連番・抽出音声まで準備済み。追加のSeedance生成は不要。まずREADME.md、manifest.json、prompts/seedance-presenter-ja.txt、audio/timing-cues.json、handoff/RECEIVED_VIDEO_NOTES.mdを読み、画像と構図見本を目で確認する。

目的は、映像を見慣れた人にも「動きとつなぎがすごい」と感じてもらえる75秒のキネティックタイポグラフィー作品。仮タイトルUNBOUND。テーマは「文字に、力が宿る」。圧縮、連鎖、通過、人物による中断、解放、収束を一つの形でつなぐ。

文字・ロゴ・帯・空間・写真の動きはHTML/CSS/SVG/Remotionで作る。実写的な人物の口・表情・手の動きのみ、ユーザー提供のSeedance動画を使う。有料動画生成APIを呼ばない。Seedanceでモーショングラフィックスを生成しない。追加の画像生成・素材購入も行わず、まず同梱素材を活かす。

出力仕様：1920×1080、30fps、2250フレーム、75秒。編集可能なRemotion/React/TypeScriptプロジェクトとH.264 MP4を作る。素材はプロジェクトのpublic配下へコピーして参照し、外部ネット画像やシステムフォントに依存しない。新規プロジェクトの置き場所は、この素材パック直下のmotion-project/。原本素材とプロンプトを上書きしない。作業と成果物はこのフォルダ内に収める。

## デザインと素材の使い方

色：背景 #050505、文字 #F5F3EC、アクセント #FF4D24。銀色写真はモノクロ。オレンジは視線誘導と接触点に使う。文字の可読性と強い余白を守る。

主見出しはArchivo wght=900 / wdth=62。日本語はNoto Sans JP wght=700。フォントファイル・CSS・OFLをtypography/に同梱。主語は短い単語PRESS、PUSH、HOLD、BREAK、FLOW、UNBOUND。AIは人物セクションの補助。コピーを増やしすぎない。

typography/words/*.svgは文字をアウトライン化済みで、各文字に安定したIDがある。typography/glyph-layouts.jsonに各文字のパス、位置、サイズ、座標系を記載。各glyphの中心を求め、文字ごとにtranslation/rotation/scaleを適用する。フォントのnative座標はy-up、SVGの親が反転している点に注意。文字の穴をマスクにするときはfill-ruleとパスの向きを確認する。

vectors/logo-loop.svgは今回作成した独自の開いた輪。6パーツを個別に動かせる。vectors/logo-morph-controls.jsonにはloop/pressure/releaseの対応した座標配列がある。同じsegment同士の座標補間で形を変えられる。文字間のパスは同じトポロジーではないため、適当にd文字列を補間しない。異なる文字への変換は分解・再構成・マスク・一致する輪郭へのカットで演出する。

images/01-pressure.png、02-release.png、03-macro.pngは同じ銀色リボンの素材写真。マスク、スライス、写真を文字に収める窓、接写の短い挿入に活用する。2枚の静止画だけから正確な金属のほどけ方を生成できたように見せない。形の連続変形が必要ならSVG/3D側で作り、写真は質感と到達点としてつなぐ。

previews/*.pngは静止画の構図見本。フッターのMATERIAL STUDY、番号、英語の補助説明は制作管理ラベルであり、完成動画に入れない。構図を固定したまま字幕だけ動かす映像にしない。

## 75秒の構成

128 BPM、40小節、全体75秒。秒数よりaudio/timing-cues.jsonのフレーム境界を優先し、セクションを重複・欠落なく接続する。

| 時間 | 演出 |
| --- | --- |
| 0–5.625 | 小さな開いた輪。逆方向のねじれで溜め、6パーツが解けて最初の大きな文字へ。小→大のスケール差で冒頭の見せ場を作る。 |
| 5.625–16.875 | PRESS、PUSH、HOLD。文字が接触し、圧縮され、反動が隣へ伝わる。潰れ・押し出し・遅れて残る揺れを別のタイミングにする。圧縮写真を文字内部へ短く見せる。 |
| 16.875–28.125 | 一文字の回転が次を動かす連鎖。横棒がレールへ、ロゴがレール上を走る。速度変化と追従カメラで空間をつなぐ。 |
| 28.125–41.25 | Oの穴から文字のトンネルへ。レイヤーの遠近か、必要ならローカルなThree.jsで奥行きを作る。出口の輪郭を銀色リボンのループへ合わせ、写真の接写へ。回転するロゴの厚みを見せる場合、実際の3Dジオメトリを使う。平面SVGの傾きを立体回転と呼ばない。 |
| 41.25–48.75 | 音の密度を下げ、切り抜いた人物が現れる。台詞「これ、どうやってAIで作るんだろう？」。人物の手が文字を押す。実際の手の動きへ文字の接触・たわみ・反動を合わせる。人物を文字の前後に挟み、平面的な貼り付け感を抑える。 |
| 48.75–65.625 | 人物の押す動きを起点にBREAK→FLOW→UNBOUND。前半の輪・帯・レールが、より大きな空間と密度で再登場。文字の帯が巻く、分割が広がる、巨大文字へ寄って引く。各瞬間の視線の主役は一つ。 |
| 65.625–75 | 散った6パーツが順に開いた輪へ戻る。最後の一片は少し遅れて噛み合う。UNBOUNDを見せ、最終2秒程度は動きを収めて余韻。必要なら小さく「自分でも、できる。」を置く。 |

場面転換は、前の場面の輪郭・方向・速度が次へ引き継がれるように設計する。フェード、毎回同じspring、装飾用グリッチの反復だけで埋めない。硬い文字、柔らかい帯、実写人物で運動の性格を分ける。動く前の溜め、速い移動、見せる静止、追いつく二次動作の順を意識する。

## 人物の生成動画と合成

実素材の推奨：video-inbox/presenter-frames/のRGBA連番を30fpsで描画し、presenter-voice.wavを同期して一度だけ再生する。フレーム1が0秒。透過WebMが正常にデコードできる場合はそちらでもよい。原本は854×480なので人物の高さは450–510px程度に抑える。約4秒以降に手が上がり、5–6秒で外側へ示す動きになる。その実際の動きを起点に文字を出す／押し広げる。原本の画質や動作を直すための有料再生成は行わない。

video-inbox/presenter-green.mp4があれば、内容を実際に確認する。8秒の予定だが、実際の尺と口・手のタイミングを優先する。声が別の場合はpresenter-voice.wav/mp3を使う。台詞の途中を切らない。必要に応じて静かな区間を少し延長・調整し、最終尺75秒を維持する。

handoff/key-presenter.shは初期設定の例。実際の動画のグリーンをサンプリングし、髪・肌・白い衣装の輪郭を確認してキーとdespillを調整する。背景色はリファレンスと一致する保証がない。透過WebMはVP9アルファ対応のデコーダーで確認する。ブラウザーで黒く見えただけでは透明と判断しない。必要ならローカル処理でアルファ付き連番PNGなど、確実に扱える中間素材に変える。

人物は切り抜いてから、文字と同じ画面へ合成する。グリーンバック映像を長方形のまま出さない。人物の手の届く場所へ文字を配置し、最大伸展の実フレームを接触点にする。人物の前を文字の一部が横切り、別の文字が後ろにあるように深度を構成する。台詞中は音を下げる。

人物動画がまだ無ければ、他のセクションの実装とプレビューは進められる。images/05-presenter-cutout.pngを静止画の仮配置に使い、プレビューに未収録であることを明示する。完成映像と報告しない。画像を揺らしただけで「話す人物動画が完成した」と扱わない。現在は実動画が揃っているので、完成本編には必ず受領した人物動画を使う。

## 音

audio/の6つの効果音は今回独自に波形合成したもの。rhythm-guide-128bpm-75s.wavは編集用のガイドで、音楽の完成版ではない。接触や停止に必要な箇所へ効果音を置き、鳴らしっぱなしにしない。ガイドと同じ効果音を二重に重ねて音割れさせない。人物の声を含めた最終ミックスはピークと聴感を確認する。

## 制作と検証

1. まず12–15秒の試作で、文字の衝突、写真のマスク、形を受け継ぐ場面転換を仕上げ、MP4と要所の静止画を出す。人物のグリーンキーは別途実素材で検証する。
2. その完成度を75秒へ展開する。RemotionはuseCurrentFrameに基づき、全ての動きがフレームから決まるようにする。CSSの時刻依存animation、setTimeout、Math.randomの未固定結果を使わない。SVGフィルターや3Dの負荷を考慮し、安定してレンダリングできる作りにする。
3. フォントのロードを待ってから描画。画像はRemotion Img/staticFileなど安定した方法でロード。元画像の寸法は1672×941なので、必要以上の接写拡大を避ける。
4. 各場面の到達点と場面転換の直前直後を静止画で確認。文字の意図しない切れ、マスク抜け、人物の緑縁、手と文字の接触ずれを修正する。試作の動画を実際に再生し、テンポと音を確認する。
5. 本編をレンダリングし、尺・解像度・フレームレート・音声の有無を確認。冒頭・終盤だけでなく全編のつなぎを確認する。最後にプロジェクト場所、MP4場所、検証内容、人物素材など未完了のものを明確に報告する。
