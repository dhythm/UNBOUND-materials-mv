# 優先順位の更新：まず12秒の動く試作を出す

ユーザーから「試作、時間かかってますね？」との指摘があった。現在17分以上を環境準備、部品作り、静止画検証に費やし、動く試作が出ていない。制作を続けるが、最初のレビュー可能な動画を出すことを最優先に変更する。

今ある motion-project/src の Glyph、Logo、Photo、layoutWord などの部品を活かし、直ちに360フレーム・30fps・1920×1080の Prototype コンポジションを実装して out/unbound-prototype.mp4 を書き出す。

試作の構成：0–2秒はロゴが力を溜めて文字へ展開。2–7秒はPRESS/PUSHの文字が異なるタイミングで衝突・圧縮・反動する。7–12秒は文字の穴／輪郭を使った写真への場面転換。useCurrentFrameで実際に動く映像にする。静止画の連結で代用しない。

既存部品で組む最初の見せ場に集中する。文字の可読性、動く前の溜め、速度差、着地、音の接触点を優先する。Prototypeを書き出すまで、75秒全体の新規設計、追加の汎用部品、試作に不要な3D機能、検証用Labの拡張へ作業を広げない。必要な型チェックと実際の書き出し・要所の目視確認を行い、動く試作を先に出す。

書き出しが終わったら、成果物のパスと実装した動きを報告する。75秒への展開はこの試作の確認後に進める。Seedanceの追加生成は不要。素材原本は変更しない。
